# 两期成本变化分解方法

## 1. 口径区分

| 口径 | 定义 | 可加性 |
| --- | --- | --- |
| 支出 cost | 观测费用合计，单位元 | 可加，分解桥的对象 |
| 工作量 work | 标准化工作单位合计 | 可加，单位成本的分母 |
| 单位成本 unit_cost | cost / work | 跨单元不可加，只在总量与单元层列示 |

总量单位成本是总成本除以总工作量，不是各单元单位成本的平均或加总。

## 2. 单元与共同支持

按配置维度（`pool`、`hardware`、`priority` 的任意非空子集，可单维可组合）把两期观测聚合为单元，每个单元保留两期的原始分子 `cost_first/cost_second` 与分母 `work_first/work_second`，聚合前按 `observation_id` 排序，结果对输入行序不敏感。

单元状态：

| 状态 | 判定 | 处理 |
| --- | --- | --- |
| evaluable | 两期均出现且两期 work 均 > 0 | 可构造反事实，做三项与 Shapley 分解 |
| entry | 仅第二期出现 | 成本差额整额计入进入贡献 |
| exit | 仅第一期出现 | 成本差额整额计入退出贡献 |
| unsupported | 两期均出现但至少一期 work = 0 | 反事实无数据支持，差额整额计入不支持桶 |

零工作量单元的单位成本显式为 `null`。不允许把空单元均价补零，也不允许丢弃零工作量但有费用的单元。

## 3. 共同支持单元上的次序无关分解

对 evaluable 单元，令 u0 = c0/w0、u1 = c1/w1：

- 价格效应：P = (u1 − u0) · w0
- 结构效应：S = u0 · (w1 − w0)
- 交互效应：I = (u1 − u0) · (w1 − w0)

恒等式 P + S + I = u1·w1 − u0·w0 = c1 − c0。三个公式对价格、工作量两个因素完全对称，不存在序贯替代，因此与因素先后次序无关；单元按键排序，与维度排列无关。

总量层把结构效应再拆为：

- 总量效应 volume = ū0 · (W1 − W0)，其中 ū0 = Σc0 / Σw0、W 为可评估单元工作量合计；
- 组合效应 mix = S − volume。

volume + mix = S，且 mix = Σ(u0_i − ū0)·(w1_i − w0_i)，只反映工作量在单元间的重新分布。

## 4. Shapley 分摊视图

价值函数（联盟 → 支出）：

| 联盟 S | v(S) |
| --- | --- |
| 空集 | u0·w0 |
| {价格} | u1·w0 |
| {结构} | u0·w1 |
| {价格, 结构} | u1·w1 |

两个因素的 Shapley 值：

- φ_价格 = ½·(u1−u0)·(w0+w1)
- φ_结构 = ½·(w1−w0)·(u0+u1)

且 φ_价格 + φ_结构 = c1 − c0；与三项视图的关系为 φ_价格 = P + I/2、φ_结构 = S + I/2，即交互项在两因素间均分。

不存在的组合：任一期工作量为零或单元仅单期出现时，v({价格})、v({结构}) 等联盟价值没有观测支撑。此时不定义 Shapley 值、不补零、不分摊，单元成本差额整额进入 entry/exit/unsupported 桶。

## 5. 可加闭合

```
total_change
  = price_effect + structure_effect + interaction_effect
    + entry_contribution + exit_contribution + unsupported_contribution
  = shapley_price_effect + shapley_structure_effect
    + entry_contribution + exit_contribution + unsupported_contribution
```

全部计算保持完整浮点精度并以 `math.fsum` 汇总，`residual`/`shapley_residual` 为浮点运算残差（正常为 0）；舍入仅由 `presentation.rounded` 在展示层执行，展示层舍入后可能出现轻微不闭合，属预期现象。

不支持反事实的比例在 `unsupported_counterfactuals` 中给出：各桶按单元成本差额绝对值占全部单元差额绝对值之和的比例，以及可评估单元在两期成本中的覆盖率。

## 6. 手算案例（业务复核用）

两期、两个单元 A 与 B（单维度 pool）：

| 单元 | c0 | w0 | u0 | c1 | w1 | u1 |
| --- | --- | --- | --- | --- | --- | --- |
| A | 100 | 10 | 10 | 132 | 12 | 11 |
| B | 60 | 10 | 6 | 70 | 10 | 7 |

单元 A：

- P = (11−10)·10 = 10
- S = 10·(12−10) = 20
- I = (11−10)·(12−10) = 2
- φ_价格 = 1·(10+12)/2 = 11；φ_结构 = 2·(10+11)/2 = 21

单元 B（工作量不变）：P = (7−6)·10 = 10，S = 0，I = 0，Shapley 同 P。

汇总：价格 20、结构 20、交互 2，总差额 42；Shapley 价格 21、结构 21。
总量效应：ū0 = 160/20 = 8，volume = 8·(22−20) = 16；mix = 20−16 = 4。

维度顺序不变性：将维度配置改为任意排列（组合维度场景），`totals` 与 `bridge` 数值完全一致，单元集合的规范序列化结果一致。

## 7. 边界情形

- 新硬件：仅第二期出现的单元记为 entry，其费用计入进入贡献，不估算价格效应。
- 硬件退出：仅第一期出现记为 exit，差额为负。
- 零工作量有费用：保留单元，单位成本为 null，状态为 unsupported（两期都在）或 entry/exit（单期出现），费用全额参与桥闭合。
- 高度相关维度（如 pool 与 hardware 一一对应）：单维度桥的单元数与效应金额相同，联合桥与单维桥都闭合到同一总差额。

## 8. 措辞边界

本分解是会计恒等式下的统计性算术归因，回答“总差额由哪些可核算部分组成”，不回答“谁导致了变化”。输出文本统一使用“效应/贡献”措辞，不作因果责任判定。
